# Peak Fuel Picks — DRAFT affiliate site (not published)

Plain static HTML/CSS. Open index.html in a browser; no build step needed.

## The one config spot
assets/config.js -> SITE_NAME, STORE_URL, AFFILIATE_PARAM ("sca_ref", UpPromote), AFFILIATE_ID, CONTACT_EMAIL.
Buy links are built from it at page load, e.g. https://theultrahuman.net/products/conscious1?sca_ref=AFFILIATE_ID
(Without JavaScript, buttons still go to the right product page, just without the ref code.)
For SEO, after picking the final name also run:  grep -rl "Peak Fuel Picks" . | xargs sed -i 's/Peak Fuel Picks/NEW NAME/g'
Pages carry <meta name="robots" content="noindex"> while in draft; remove it before going live.

## Optional
../build.py regenerates every page from one file of copy (python3 build.py). Not required for hosting.

## Cart and checkout handoff (draft)
- Product pages have a size/flavor picker, quantity and **Add to cart**. The cart drawer (bag icon, top right) lives only in the visitor's browser (localStorage key `pfp_cart_v1`).
- **Secure checkout** sends the visitor to the official store using a Shopify cart permalink:
  `https://theultrahuman.net/cart/VARIANT:QTY,VARIANT:QTY?storefront=true&sca_ref=YOUR_CODE`
  With `CHECKOUT_MODE: "cart"` (default) they land on the store's cart page, pre-filled, and click Check out there.
  With `"checkout"`, `storefront=true` is dropped and they go straight to Shopify checkout.
- Variant IDs and prices are in `assets/catalog.js` (generated by `build.py` from the store's products.json, Oct 2026). If the store changes prices or adds flavors, update `packs=` in build.py and re-run it. The store's checkout price is always the final price.
- Affiliate code: set `AFFILIATE_ID` in `assets/config.js` to the full UpPromote code, e.g. `1234567.AbCdEfGh` (the number, a dot, then the hash, exactly as in your UpPromote link).
- Test results (Oct 28, 2026, headless Chromium, no order placed):
  - Both modes landed with the right items, quantities and a $246 subtotal.
  - Cart mode: the store's UpPromote script ran, called its click-tracking API and set the cookies `up_uppromote_aid=1234567`, `up_uppromote_hs=AbCdEfGh` and `scaaf_aid`.
  - Checkout mode: UpPromote's Shopify web pixel read the code and sent `affiliate_id 1234567`.
  - Because the test code was made up, UpPromote answered "Affiliate not found". Crediting a real referral is UNVERIFIED until a real code is set: click once, then check the click count in the UpPromote dashboard.
